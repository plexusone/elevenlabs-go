# v0.15.1 — Language Tags for Speech-to-Text

**Release date:** 2026-11-17

This release fixes OmniVoice speech-to-text with a language set. OmniVoice
configurations use BCP 47 tags such as `en-US`, and ElevenLabs rejected them:
it expects ISO 639-3 codes such as `eng`.

## Fixed

- OmniVoice STT converts `TranscriptionConfig.Language` before sending it,
  for batch (`Transcribe`, `TranscribeFile`, `TranscribeURL`) and WebSocket
  (`TranscribeStream`) transcription:
  - `en-US` and `en` are sent as `eng`, `fr-CA` as `fra`, `pt_BR` as `por`;
  - an empty tag stays empty, so ElevenLabs detects the language;
  - a three-letter code is sent as given;
  - a tag that can't be parsed is passed through for the API to report.

## Added

- `omnivoice.LanguageCode(tag)` returns the ISO 639-3 code for a BCP 47
  tag

## Dependencies

- `golang.org/x/text` v0.44.0, now a direct dependency

## Documentation

- [OmniVoice STT guide](../omnivoice/stt.md#configuration-options): language
  tags
